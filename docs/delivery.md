# Сдача: ссылки для комиссии

Страница собирает ссылки, которые комиссия получает вместе с решением. Целиком её
собирает задача `Q9.7` (MOS-81): репозиторий, презентация, прототип, документация,
демо-стенд и видеозапись. Сейчас здесь одна строка — демо-стенд из задачи `Q1.10`
(MOS-109); остальные пять допишет `Q9.7`.

## Демо-стенд

**Адрес:** https://135-106-216-101.sslip.io:8443 (основной стенд — https://moskollektor.mbogatyreva.ru,
у него вход для проверок нашими скриптами, а не для комиссии) — демо открывается в браузере с любой
машины, без установки и без правки `/etc/hosts`. Сертификат выпущен Let's Encrypt,
предупреждения о безопасности браузер не покажет. Если оно всё же появилось,
сертификат истёк (он живёт 90 суток) — это не поломка решения, продлевает его
`deploy/demo-cert.sh`.

**Учётки** подсказывает сам экран входа:

| Логин | Пароль | Роль | Что видит |
|---|---|---|---|
| `disp2` | `disp2123123` | диспетчер | риски, прогнозы, объекты и заявки своего района: коллекторы Альфа и Гамма, 512 участков из 3 173 |
| `ods1` | `ods123456` | диспетчер ОДС | то же по всему парку |
| `tech1` | `tech123456` | техник | то же по своему комплексу |
| `admin1` | `admin123456` | администратор ИС | настройки, журнал действий, служба каталогов |

**Данные** — копия базы нашего основного стенда: вся выгрузка заказчика
и прогнозы, посчитанные на ней. Расчёт на демо не идёт, прогноз показан на момент
копии.
