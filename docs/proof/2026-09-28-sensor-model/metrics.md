Источник всех чисел — `run.json`, текущий экспорт `sensor_model.json`. Выбран H=12 ч по F1 реальной модели на январе–марте. Обе модели обучены только по 2025 год, коэффициенты и пороги после выбора не менялись. Апрель–июнь уже использовались в исследовании: это ретроспективная проверка, не нетронутый holdout.

Срезы ежедневно в 21:00 МСК. Окно выбора: 01.01–30.03; ретроспектива: 01.04–29.06, события до 30.06 09:00. Последний календарный день каждого периода исключён консервативно. Метка — следующий эпизод D5 канала; это не подтверждённая актом поломка самого датчика. Плановый демонтаж газа с `match=sure` исключён.

**Итоговый режим экрана «с синтетикой» объединяет две ветви**, а не показывает синтетическую ветвь отдельно. Балл `1−(1−p_real)(1−p_sim)`, уровень — максимум уровней ветвей. На объединённых 913 событиях (601 реальное + 312 искусственных) результат high: **TP 156, FP 1024, FN 757, P 0,1322, R 0,1709**. На выборе: TP 144, FP 678, FN 419, P 0,1752, R 0,2558. Это симуляция при заданных допущениях, не качество на реальных поломках. Воспроизводимый расчёт и проверка публичной функции runtime: `combined_demo.py` и `combined_demo.json`.

На H=12 упреждение ≥24 ч невозможно. Все засчитанные попадания имеют упреждение менее суток. Эти числа не заменяют М-18…М-20 модели коллектора v3.

## Проверенные ограничения

- Признаки видят D5 только после начала +3601 с; будущие поверки не меняют прежние предупреждения симулятора.
- Текущий активный парк применён к прошлым периодам: исторические окна присутствия каналов неизвестны. Время поступления архивных записей неизвестно; причинность проверена по времени события.
- Два отдельных источника исходов объединены формулой независимого объединения вероятностей — это допущение демо, калибровка итоговой вероятности не доказана.
- Доля первых отказов ранее была ошибочно названа 70%. На исходном архиве: 75/292 (25,7%) на выборе, 94/601 (15,6%) на ретроспективе. Это не объясняет низкое качество само по себе.
- Полные вероятности и решения экспортированной модели сверены на каждой строке обоих окон и режимов; скалярный runtime проверен на выборке, включая ближайшие к порогам строки.
- Worker пересчитывает по времени последнего прогноза коллектора; метрики относятся только к зафиксированному расписанию 21:00. Иное расписание и реальные действия диспетчера требуют отдельного замера.

Сильное правило для симуляции: наблюдённое предупреждение + фиксированный P-F попадает в ближайшие H часов. Оно не знает флага истинности. На ретроспективе TP 146 / FP 156 / FN 166, P 0,4834 / R 0,4679; синтетическая LR даёт те же 146 попаданий при 505 ложных. Поэтому превосходство LR не доказано и в симуляции. Расчёт — combined_demo.json.
