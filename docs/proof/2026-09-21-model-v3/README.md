# Доказательства к отчёту об обучении модели, 21.09.2026

Здесь лежит то, на что ссылается `docs/ml-training-report.md`. Каталог нужен потому,
что сама модель живёт в репозитории ML-команды, а его на приёмке не откроют: комиссия
читает наш репозиторий и должна проверить каждое число, не выходя из него.

## Что где

|---|---|
| `excerpts.md` | дословные строки файлов ML-команды с теми же номерами, что в отчёте: границы окон, гиперпараметры, состав признаков, строка `COPY models/current` в `Dockerfile` |

### Что можно проверить прямо здесь, а что требует бандла

**Без бандла проверяются числа отчёта.** Выписки в `excerpts.md` дословные,
с номерами строк, и всё, на что ссылается `docs/ml-training-report.md`, читается
из них: границы окон, гиперпараметры, состав признаков, строка `COPY models/current`
в `Dockerfile`. Логи прогона лежат рядом целиком.

**Бандл нужен только для одного — доказать, что выписки не разошлись с источником:**

```bash
git clone --branch autoresearch/sep20v3 lct-task8-sep20v3_20260920.bundle ml-repo
cd ml-repo && shasum -a 256 -c ../sha256sums.txt
```

**Самого бандла в этом репозитории нет** — это архив чужого репозитория, и решение
о том, класть ли его в git, принимает команда, а не автор этого каталога. Но файл
не потерян: он лежит на сервере проекта рядом с другими крупными файлами, которые
мы держим вне git, — там же, где выгрузка заказчика и книги (`docs/server.md`).

```bash
rsync -av nikolay-hakaton@135.106.216.101:/srv/moskollektor-hakaton-data/ml-bundle/ ./
shasum -a 256 lct-task8-sep20v3_20260920.bundle
# 501f742b9ed6036af90a1bac3e44c3586d8825e8ca23cae3ae67b22a80f0e5c6
```

Если сервера под рукой нет, бандл можно получить у ML-команды: попросить сам файл
`lct-task8-sep20v3_20260920.bundle` или попросить собрать такой же заново командой
`git bundle create` из ветки `autoresearch/sep20v3` на коммите
`e76d69c8a22a3ce128b9717d8f708c48f9943c0d`.

Если бандл окажется другим, это будет видно сразу: sha256 архива назван выше,
а `shasum -a 256 -c sha256sums.txt` покажет, какой именно файл разошёлся.

Логи прогона в бандл не входят: обучение и проверку 21.09.2026 запускали мы,
логи — результат нашего прогона, а не содержимое присланного архива.

## Чего здесь нет

**Файла весов.** Его нет ни здесь, ни в бандле, ни в образе `ml` на стенде —
почему, написано в разделе 8 отчёта. Пока весов нет, строка приёмки М-01 остаётся
открытой, каким бы полным ни был отчёт.

**Данных обучения.** В `.gitignore` ML-команды первой строкой стоит `data/`
с пометкой «Confidential hackathon data (Правила ЛЦТ п. 6.3.4–6.3.5): never commit».
В репозиторий они не поедут и здесь не лежат.

**Самого бандла.** Числа отчёта он не подтверждает — их подтверждают выписки
и логи, которые лежат здесь. Он нужен только для сверки выписок с источником
и лежит на сервере проекта, команда выше.
