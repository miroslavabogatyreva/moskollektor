# Доказательства замера метрик, 21.09.2026

Здесь лежат исходники и результаты трёх замеров, сделанных в день проверки модели
Николая. Каталог нужен на приёмке: числа в `docs/acceptance-test.md` и в
`docs/explanatory-note.md` ссылаются сюда, и комиссия вправе их пересчитать.

## Что где

`our-metric/` — прогон модели Николая нашей приёмочной методикой.

| Файл | Что внутри |
|---|---|
| `alerts.csv` | 166 предупреждений модели на окне 01.04–30.06.2026: ключ объекта, время выдачи, признак «в теле» |
| `fails_db.csv` | отказы из нашей базы по нашему определению: `Неисправен`, эпизод длиннее часа, закрытый |
| `ch2collector.csv` | связка «канал → коллектор» из `smvu.object_tree`, по ней предупреждения раскладываются на 16 коллекторов |
| `incidents_pfx.csv` | инциденты по ключу Николая — префиксу тега, для сверки |
| `our_metric.py`, `run_alerts.py` | код прогона |
| `table.csv` | итоговая таблица из пяти методик |
| `run.log`, `run_meta.txt` | журнал прогона и версии |

Главное число отсюда: **нашей методикой (коллектор, окно 24…168 часов, склейка
10 минут) модель даёт Precision 0,600 и Recall 0,528**, тогда как своей методикой
Николая (префикс, окно 0…720 часов, склейка 60 минут) — 0,910 и 0,841. Контрольная
точка сошлась: прогон воспроизвёл его 0,910 / 0,841 до третьего знака, значит
судили ту самую модель.

`db-check/` — шесть вариантов разметки отказа и разложение расхождения инцидентов.
Отсюда цепочка: наши 176 инцидентов → словарь D5 даёт +22 → незакрытые эпизоды +0
→ ключ по префиксу +1 → окно склейки 60 минут вместо 10 даёт −29 → его 170.

`undefined-2nd/` — второй, независимый счёт по значению `Неопределен` (задача MOS-133).
Первый счёт лежит рядом в `a1-full.sql` и `a1-v2.sql`.

## Осторожно: первый счёт серий неверен

Файлы `a1-full.sql` и `a1-v2.sql` дают 82 971 серию `Неопределен` и долю закрытия
отказом 3,99 %. Оба числа неверны, и это видно без базы: при максимальной длине серии
в 9 записей 82 971 серия вмещает не больше 746 739 записей, а записей значения в окне
1 122 226. Запрос группировал серии по сменам значения, а не по всему потоку канала.

Верные числа даёт `undefined-2nd/`: серий 1 113 769, сумма их длин 1 122 226 — сходится
с числом записей до единицы, закрытие «Нормой» 99,22 %, закрытие отказом 0,30 %.
Вывод обоих счётов одинаков: `Неопределен` отказ не предвещает.

Файлы первого счёта оставлены намеренно — на приёмке мы показываем, что сверяли
замер вторым счётом и что именно он поймал.
