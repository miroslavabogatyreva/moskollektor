# Исследовательские веса модели коллектора v3

25 бустеров LightGBM (`booster_42.txt`…`booster_66.txt`) и `model_meta.json`
сохранены из прежней модели коллектора. Горизонт — **720 часов (30 суток)**,
порог предупреждения — 0,63. В текущем прогнозе диспетчера эти веса не используются:
продукт считает правила датчика на 24 часа, см. [описание](../../sensor/README.md).

Файлы извлечены 28.09.2026 из прежних образов стенда. Их целостность проверяется:

```sh
shasum -a 256 -c SHA256SUMS
```

`train_code_sha256` в метаданных фиксирует исторический код обучения. Само обучение
этой модели и его экспериментальное окружение исключены из текущей поставки.
Наличие весов позволяет проверить загрузку и контракт, но не означает, что обучение
воспроизводится из текущего каталога или что качество относится к горизонту 24 часа.
