# Внешние входы прежнего кандидата

Все пути ниже относительны к `ml-model/`. Эти файлы не входят в PR. Внешние веса
на 720 часов нужны только для разбора старого кандидата; на стенд их не ставят.

| Для чего | Внешний вход |
|---|---|
| HTTP-инференс существующего кандидата | Каталог `models/v3_collector_20260922/`: `model_meta.json`, 25 файлов `booster_*.txt`, `channels.parquet`; точные имена и хеши в `ml-model/docs/external-artifacts.json` |
| Пересчёт признаков на срезе | `data/02_interim/mk/parquet/j2019.parquet` … `j2026.parquet`; формат строк `ev, ch, ts, alarm, val`; предел среза определяется фактическим журналом |
| Склейка инцидентов и метрики | `data/02_interim/mk/predictive_metrics.py` — внешний вариант методики, использованный кандидатом. Его нельзя молча заменить нынешним `code/predictive_metrics.py`: равенство версий нужно проверить отдельно |
| Сборка прямой привязки | `data/01_raw/dataset_update_20260916/справочник_каналов_датчиков.csv` и `data/01_raw/dataset_20260915/справочник_объектов_диспетчер.csv` |
| Прежний рецепт обучения | Дополнительно `data/03_processed/ml_20260915/chanday.parquet` и `data/03_processed/faildef_20260915/D5/episodes_ext.parquet` — подготовленные реальные агрегаты и эпизоды. Сборщик первичных CSV/кэшей сюда не переносится; рецепт не является установкой «из ничего» |
| Полная сверка через `--check` | Отдельный reference dataset, указанный в metadata модели; для прежнего collector-кандидата `data/03_processed/v3_collector_20260922/` |

Внутреннее поле `pfx` в замороженном коде обучения содержит collector ID у этого
кандидата. Это техническое имя столбца, а не разрешение восстанавливать коллектор
по префиксу тега. Сервис сообщает `object_level=collector` и фактический горизонт
из metadata. Вклады относятся к среднему логиту деревьев; они не объясняют целиком
медиану, голову rearm и калибровку итоговой вероятности.

Q2 2026 уже видели до этой упаковки. Старые функции выбора порога и оценки сохранены
без запуска, но их имена не доказывают независимую валидацию. Для требуемых 24 часов
нужны новые веса, выбор порога и документированный протокол оценки.
