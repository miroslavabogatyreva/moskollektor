# Local24: сквозной исследовательский результат, 23.09.2026

> Продолжение: [аудит цели, привязки, источников и новые эксперименты](../research/local24_audit_20260923/README.md). Этот документ сохраняет результаты первой серии; поздние проверки не превратили её в принятый кандидат.

**Модель обучена на реальные пикетные участки и следующие 24 часа; транспорт
модель → API → БД → интерфейс проверен. Полезное улучшение над правилом недавности
не доказано. Кандидат не принят для продуктивного переключения.**

Это новая задача относительно прежних v1/v2/v3. Предыдущие 720-часовые числа не
переносятся на неё. `section_id` — продуктовый пикет, а не 78 узлов дерева объектов.
Источник требования: MOS-217, MOS-219 и уточнение Мирославы 23 сентября.

## Данные и граница результата

Набор с 2022-04-09 по 2026-06-29 содержит 4 267 349 допустимых участко-суток,
1 713 положительных участко-суток и 2 901 начало D5-эпизода в доступных окнах.
Глобальный календарь содержит 1 534 дня. 40 исходных признаков, 3 172 однозначных
пикетных участка, 16 коллекторов. Одна неоднозначная пространственная привязка
исключена; текущая привязка предполагается исторически стабильной, её версий нет.

Текущие D5-состояния исключаются причинно, включая будущие короткие эпизоды:
их будущая длительность для решения не используется. Признаки — только прошлые
полные сутки и уже известные подтверждения/восстановления. Пропуски архива и
неполный хвост цензурируются отдельно. Ненаблюдавшиеся ещё каналы не создают
историческую экспозицию. 2021 исключён согласно ответу заказчика; старая история
2019–2020 не включалась в эту серию. Не все доступные источники уже испытаны.

D5 — выбранное командой состояние журнала длительностью больше часа, не
подтверждённая физическая поломка. Актов ремонта и независимой разметки нет.
Весь реестр событий этой серии также ограничен однозначно локализуемыми каналами;
его «все события» не означает все события исходного парка.

## Эксперименты

12 заранее перечисленных гипотез: восемь базовых вариантов и четыре дополнительных
преобразования признаков. Отбор — только 2025Q2/Q3/Q4, seed 42; у выбранного первого
кандидата пять сидов 42–46 и фиксированное среднее откалиброванных вероятностей.
ES 30 дней и калибровка 30 дней отделены друг от друга и от оценки двухдневными зазорами.
В отрицательных обучающих строках используется ограниченная подвыборка с обратными
весами вероятности включения. Все оценочные строки сохраняются.

Первый кандидат `short_history`: среднее Precision@10 разработки 1,9983%,
правило недавности 1,9613%. Выигрыш — одно дополнительное попадание из 2750
рекомендаций. Парный bootstrap по дням не подтверждает его устойчивость:
95% интервал разницы −0,582…+0,617 процентного пункта.

| Известный период | ML, попаданий/рекомендаций | Недавность | История 365 дней |
|---|---:|---:|---:|
| 2026Q1 | 17/900 (1,89%) | 19/900 (2,11%) | 7/900 (0,78%) |
| 2026Q2 | 47/870 (5,40%) | 45/870 (5,17%) | 20/870 (2,30%) |
| Вместе | **64/1770** | **64/1770** | 27/1770 |

На Q2 полнота по доступным положительным участко-суткам 13,47%; одно-к-одному
сопоставление с событиями всего календаря 7,57%. Эти знаменатели различаются и
не объединяются в одну confusion matrix. Целевые 0,7/0,5 не достигнуты.

Вторая серия: нормировка на каналы/объём, краткосрочные изменения и контекст
коллектора. Все четыре варианта отклонены на разработке; лучший 1,8160% хуже
первого кандидата и простого правила. Для них не создавались новые веса поставки
и не выполнялся повторный подбор по 2026. Все исходные результаты сохранены.

Q1/Q2 уже изучались ранее и остаются **development replay**, не новым holdout.
`development_pass` в JSON — только правило выбора кандидата. Итоговый quality gate
этой работы — NOT ACCEPTED. Не менять смысл поля на сертификат качества.

## Реальная сквозная проверка

На 15 июня 2026 пересчёт из усечённого архива дал 3110 участков; на 15 мая —3164.
Офлайн-признаки и вероятности совпали с причинным пересчётом точно. `/model`
возвращает `object_level=section`, `horizon_h=24`; `/predict` отклоняет 720.
Локальная ветка HTTP сохраняет полную точность вероятности, без округления 6 знаков.

Продуктовый прогон№ 5: score → HTTP → DB → API совпали с максимальной ошибкой 0.
Вероятности различаются внутри всех 16 коллекторов; разнос по историческим весам
явно отключён. Интерфейс показывает 10 приоритетных участков и экспериментальный
статус отдельно от класса риска. Автозаявки выключены; счётчики заявок и уведомлений
до/после 352/352. Это проверка архива на отдельной БД, не live-потока.

Новые ML-проверки:25 passed. Дополнительные 12 исторических serving-тестов пропущены
из-за отсутствия старых внешних весов в изолированном checkout. Продукт:90 passed,
новый Playwright-сценарий 1 passed, frontend build и проверка схемы прошли.
Полная причинная оценка/упаковка не заменяет приёмку качества.

## Воспроизведение и поставка

`ml.local24_data` строит набор из реальной продуктовой привязки и существующих
Parquet. `scripts/ml_local24_research.py run` запускает восемь вариантов,
`--series 2` — отдельные четыре; `verify` сохраняет веса первого кандидата.
Файлы данных, рядовые прогнозы и веса не входят в Git.

`scripts/ml_local24_score.py --model <weights> --data <data> --as-of 2026-06-15
--out <score.json>` выполняет явный архивный расчёт. Пока поддержана только
ежедневная точка 00:00 Europe/Moscow; даты до обучения и после данных отклоняются.
`ml_local24_package.py` создаёт локальный переносимый пакет с весами, минимальными
входами, Dockerfile и хешами; сырой журнал 313 млнстрок для инференса не требуется.
Веса не переключают `models/current` и автоматически не публикуются.

Итог исследования: локальный 24-часовой контракт реализован, но оснований
заменить сильное простое правило моделью по качеству пока нет. MOS-217/MOS-219
оставлены открытыми до решения команды и согласования приёмки.

См. [протокол](PROTOCOL.md), [вторую серию](SERIES2.md),
[независимый разбор](independent-review.md), [данные](dataset-manifest.json).

Переносимый пакет проверен после свежей распаковки: 30 хешей совпали.
Arm64 Docker: 3 110 участков за 6,60 с, признаки совпали точно, максимальная
разница вероятностей с нативным расчётом 4,34×10⁻¹⁹. Первое испытание выявило
недоступный непривилегированному процессу каталог spill; исправлен отдельный
временный каталог DuckDB. См. [квитанцию](portable-proof.json).
