# Local24, серия 2: четыре гипотезы признаков

Зафиксировано до её первого обучения. Первая серия из восьми вариантов не доказала
улучшения против recency: на известном replay 2026Q1+Q2 по 64 попадания из 1770
рекомендаций. История сохранена целиком; `development_pass` означал только прохождение
правила отбора, не приёмку качества.

Вторая серия сохраняет исходные риск-множество, цель, календарь, бюджеты и временные
разрезы. Отбор только на 2025Q2/Q3/Q4. 2026 уже изучен, повторная оценка остаётся
development replay; новый holdout не появился. Исходные 40 признаков не меняются.

Четыре гипотезы: короткая история с нормированными долями и трендами;
короткая история с контекстом коллектора на тот же момент; обе группы вместе;
обе группы вместе с длинной историей. Параметры дерева те же, что у исходного
простого варианта. Нормировка учитывает только ранее наблюдавшиеся каналы;
контекст собирается из полного причинного риск-множества одного момента до
подвыборки обучающих строк. Ни метки, ни количество будущих событий не читаются.

Из опыта v2 известно, что похожие преобразования часто не давали выигрыша на
коллекторной задаче. Это ограниченная повторная проверка на новой локальной цели,
а не предположение, что нормировка обязательно улучшит результат.

Лучший вариант второй серии сравнивается с зафиксированным первым кандидатом
по тем же трём блокам разработки. При ухудшении новый вариант не заменяет первый.
Пять сидов 42–46, среднее индивидуально откалиброванных вероятностей; проверка
на 2025Q4, затем на известных 2026Q1/Q2. Критерий полезности требует устойчивого
выигрыша над простыми правилами, а не одного положительного округлённого числа.
