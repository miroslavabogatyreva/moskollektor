# Дополнительные источники: протокол до обучения

Зафиксировано после серии 3 и проверки V3: sensor V3 —61/2750, собственный
control —52/2750, правило недавности —54/2750. Статистического доказательства нет.

Проверяем две отдельные причины потери сигнала, сохраняя исходные D5-метки,
риск-набор 2025Q2/Q3/Q4, K=10, разбиение fit/ES/calibration и зазоры.
В каждом сравнении пять сидов42–46 и одинаковое усреднение дневных процентильных
рангов. Не подбираем параметры по2026. Замороженные старые результаты сохраняются.

1. **Внутридневные числа.** К sensor V3 добавляются18 признаков, по6 для газа,
   температуры иИБП: максимум диапазона/std/IQR относительно собственной прошлой
   28-дневной шкалы канала, плато, смена постоянного уровня и объём числовых записей.
   Все исходные записи раньше момента прогноза. Единицы разных приборов не смешиваются.
   Известные технические коды исключаются только без признака тревоги, согласноQ&A.
   Это признаки поведения журнала, не физически откалиброванные показатели.
2. **2019–2020.** К обучению базовой модели добавляются только разрешённые исторические
   строки, D5 пересобирается тем же словарём и порядком(ts,ev). Контроль —тот же
   canonical V3 control_short на2022+. Числовой набор38 признаков одинаковый;
   sensor-признаки в этом сравнении не используются, поскольку их старой версии нет.
   2021 полностью исключён, окна через разрыв не продолжаются. Текущая привязка
   применяется к старой истории условно; непокрытые каналы не становятся отрицательными
   примерами. Short7/28 используют положительные закрытые интервалы без точных копий.

Критерий продвижения прежний: абсолютный прирост среднегоP@10≥0.005, минимум2фолда,
парный недельный интервал не включает0. Все результаты остаются разработкой:
нового независимого периода и подтверждённой физической разметки не появилось.
