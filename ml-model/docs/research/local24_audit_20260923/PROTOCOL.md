# Аудит и третья серия Local24 — протокол до результатов

Задача: проверить цель, привязку, неиспользованные источники и историю датчиков.
Старые результаты/модели не переписываются. Целевая единица — реальный продуктовый
участок, горизонт 24 часа, бюджет 10 рекомендаций в день. D5 — операционная метка
состояния журнала, не доказательство физической поломки. Изменение группировки или
экспозиции оценивается отдельно; нельзя улучшать метрику переименованием цели.

Третья серия использует тот же риск-набор и D5-метки. Контроль — short_history.
Восемь гипотез: добавление истории отдельных каналов; только история каналов;
ранняя остановка по average_precision; последний год обучения; архивная погода;
Poisson для числа начал; LambdaRank для дневного ранжирования; длинная история.
Из прошлой работы перенесены идеи оценки верхней части выдачи и дополнительного
числа событий, а не старые показатели 720-часового протокола.

Выбор: 2025Q2/Q3/Q4, seed42, те же раздельные ES/калибровочные периоды и purge2d.
Для новых моделей числа — ранговые оценки, не откалиброванные вероятности.
Погода заканчивается за двое суток до момента прогноза. Это архивный reanalysis:
исторические версии публикации отсутствуют, пригодность для real-time не доказана.
Калибровочный период не используется как дополнительное обучение новых вариантов.

Кандидат для дальнейшей проверки: прирост среднего Precision@10 не менее0.005
абсолютно, выигрыш минимум в двух фолдах против сильнейшего простого правила,
проверка пяти сидов и парный блочный bootstrap по неделям. Q1/Q2 2026 уже известны,
новым независимым тестом не являются. При отсутствии выигрыша сохранить отрицательные
результаты и причины. Отдельные sensitivity-аудиты не участвуют в подборе метки.

Источники2019–2020 проверяются на структуру/охват;2021 исключён по ответу заказчика.
Изменившаяся пространственная привязка не переносится назад без проверки.
