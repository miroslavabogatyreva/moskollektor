# Проверка устойчивости и исправление представления эпизодов

Зафиксировано после серии 3: sensor_short 58/2750, control 55, recency 54.
Разница ниже порога 0.005. Не выбираем новый квартал и не заявляем приёмку.

1. Проверить пять сидов 42–46 на тех же 2025Q2/Q3/Q4 для sensor_v2 и control.
   Среднее дневных процентильных рангов приводит некалиброванные модели к общей
   шкале без использования y. Это новая заранее указанная агрегация, не замена
   прошлой серии с усреднением калиброванных вероятностей; сравнение только между
   одинаково обработанными control и sensor. Отдельные метрики отдельных сидов сохраняются.
2. Независимый аудит обнаружил нулевые по длительности и точно дублированные
   короткие эпизоды. Версия v3 использует положительную известную длительность,
   dedup наблюдаемых полей после цензуры будущих окончаний. Проверка усечённого
   префикса обязательна. Цели и состав строк остаются прежними.
3. V3 возвращает корректную историю длинных эпизодов, потерянную консервативной
   исключении неоднозначных групп в v2; short7/28 заменяются числом положительных закрытых эпизодов.
   Пять сидов, та же модель sensor_short. Это обоснованная корректировка представления,
   не новая оптимизация метки. Все версии и неудачи сохраняются.
4. Критерий принятия остаётся прежним. Независимый bootstrap блоками недель.
   Устойчивость на повторно использованных датах не является новым holdout.

Для V3 пересчитывается и собственный control_short на исправленных short7/28.
Это отделяет эффект исправления входных данных от добавления sensor-признаков.
Пять сидов не являются пятью независимыми временными выборками.
